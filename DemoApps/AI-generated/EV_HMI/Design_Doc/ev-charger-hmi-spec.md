# EV 充电桩 HMI 整体设计

7 寸 800×480 LCD + 电容触控 · 户外交流/直流充电桩 · 单枪或双枪

---

## 1. 设计目标与约束

| 项目 | 要求 |
|---|---|
| 用户 | 陌生司机，零学习成本；可能戴手套、夜间、雨天、正午阳光 |
| 核心任务 | 插枪 → 授权 → 充电 → 结算 → 拔枪，全程无需说明书 |
| 首要指标 | 首次用户 30 s 内开始充电；误触率 < 5%；1 m 外可读关键数字 |
| 屏幕 | 800×480，约 133 dpi，1 mm ≈ 5.2 px |
| 触控 | 电容式，需支持薄手套；雨滴误触过滤 |
| 亮度 | 光敏自动调节，白天 100%，夜间 30% |
| 语言 | 中文 / 英文，运行时切换 |
| 合规 | 费用显示需含单价与总额；故障页需含客服联系方式 |

## 2. 设计令牌（Design Tokens）

### 2.1 颜色

| 名称 | 值 | 用途 |
|---|---|---|
| base | `#101418` | 全局背景 |
| surface | `#1A2028` | 卡片、顶栏 |
| line | `#2C3540` | 分隔线、描边 |
| text | `#F2F4F6` | 主文字 |
| text-dim | `#9AA4B0` | 辅助文字、单位、标签 |
| blue | `#3B8BEB` | 空闲 / 可用 / 中性动作 |
| green | `#2FBF71` | 充电中 / 成功 |
| amber | `#F0B23C` | 等待 / 提示 / 需用户动作 |
| red | `#E5483F` | 故障 / 停止 |

规则：状态色只做背景强调或描边，不做大面积填充（故障页除外）。文字对比度 ≥ 7:1。

### 2.2 字体

| 层级 | 字号 | 用途 |
|---|---|---|
| numeral | 96 px，等宽数字 | kWh、费用大数字 |
| title | 48 px | 页面主提示（"请插入充电枪"） |
| body | 32 px | 数值、按钮文字 |
| caption | 24 px | 单位、标签、底部提示 |

只用这四个字号。中文用思源黑体 / Noto Sans CJK，英文同族，避免混排跳动。

### 2.3 间距与触控

- 网格基准 10 px；页面内边距 30 px。
- 触控目标最小 60×60 px，主按钮高 ≥ 100 px，间距 ≥ 16 px。
- 屏幕四边 20 px 触控死区。
- 圆角：按钮 12 px，卡片 16 px，弹窗 20 px。

## 3. 页面地图与状态机

```
              ┌──────────────────────────────────────────┐
              │                                          │
  [Idle] ─插枪─▶ [Connected] ─授权成功─▶ [Charging] ─停止/充满─▶ [Summary]
     ▲              │ 60s超时                  │                    │
     │              └───取消──────┐            │                    │ 拔枪 或 30s
     └────────────────────────────┴────────────┼────────────────────┘
                                               │
  任意页面 ── 故障 ──▶ [Fault] ── 重试成功 ──▶ 回到故障前页面
```

| 页面 | 进入条件 | 退出条件 | 自动超时 |
|---|---|---|---|
| Idle | 上电 / 结算完成 | 检测到插枪 | — |
| Connected（授权） | 枪已锁定 | 授权成功 / 取消 / 超时 | 60 s → Idle |
| Charging | 授权成功且开始输出 | 用户停止 / 车辆满电 / 故障 | — |
| Summary | 充电结束 | 拔枪 / 点"完成" | 30 s → Idle |
| Fault | 任意故障事件 | 重试成功 / 维护人员清除 | — |
| Settings（隐藏） | 顶栏桩号长按 5 s + PIN | 返回 | 120 s |

深度最多 2 层。除 Settings 外，用户不需要"返回"键。

## 4. 共用元素

### 4.1 顶栏（y 0–70，surface 底色）

| 区域 | x 范围 | 内容 |
|---|---|---|
| 左 | 30–300 | 桩号（caption）+ 枪 A / 枪 B 状态圆点（12 px） |
| 中 | 300–500 | 当前页标题（body），居中 |
| 右 | 500–770 | 网络图标、信号强度、时间 HH:MM（caption） |

顶栏在所有页面固定，不随页面切换动画。

### 4.2 按钮样式

| 类型 | 外观 | 用途 |
|---|---|---|
| primary | blue 填充，text 文字 | 完成、重试 |
| danger | 透明底，red 2 px 描边，red 文字 | 停止充电 |
| ghost | 透明底，line 描边，text-dim 文字 | 取消 |

按下态：填充亮度 +15%，描边加粗到 3 px，100 ms 内响应。

### 4.3 弹窗

居中 500×240，surface 底，20 px 圆角，四周 60% 黑色遮罩。出现后 300 ms 内忽略触控。按钮并排各 200×80，"取消"在左，确认动作在右。

### 5.6 Settings — 维护（隐藏）

顶栏桩号长按 5 s，弹 PIN 数字键盘（3×4，每键 90×70）。进入后左侧列表（网络、电价、语言、亮度、自检、日志），右侧详情。不面向司机，不做多语言之外的美化。

## 6. 触控与防误触规则

1. 死区：四边 20 px。
2. 去抖：按下 50 ms 稳定后才发 press；释放 30 ms 后发 release。
3. 长按：≥ 1.5 s，仅"停止充电"和"桩号"响应。
4. 弹窗锁：弹窗出现后 300 ms 忽略触控。
5. 雨滴：触控 IC 上报面积 > 阈值或多点同时出现 > 3 点，丢弃。
6. 页面切换后 200 ms 忽略触控，防止上一页按钮被"穿透"点击。
7. 每次触控伴随 30 ms 蜂鸣（可在设置关闭）。

## 7. 反馈与动效

| 场景 | 反馈 |
|---|---|
| 按钮按下 | 100 ms 内变色 + 蜂鸣 |
| 页面切换 | 内容区 150 ms 淡入，顶栏不动 |
| 授权成功 | 右半区 green 描边闪 1 次 |
| 充电中 | 车辆图标 1 Hz 脉动，证明系统活着 |
| 故障 | 蜂鸣 3 声，屏幕亮度强制 100% |
| 无操作超时 | 最后 10 s 倒计时显示在按钮下方 |

不做页面级滑动动画（SPI 带宽有限且用户不需要）。

## 8. 多语言

- 所有文本走资源表，key → {zh, en}。
- 英文平均比中文宽 1.6–2 倍，所有文本框按英文最长字串预留。
- 数字、单位、时间格式不翻译，统一 `12.4 kWh`、`¥25.92`、`0:38`。
- 语言切换入口在 Settings；顶栏可选放一个 60×60 语言图标（右侧时间左边）。

## 9. EVE 实现方案（BT817 / BT820）

### 9.1 资源预算

| 资源 | 格式 | 大小 |
|---|---|---|
| 字体 24 / 32 / 48 (CJK 常用 ~600 字 + ASCII) | ASTC 4×4 | ~360 KB |
| 数字字体 96 (0–9 . : ¥ kW h %) | ASTC 4×4 | ~40 KB |
| 图标 ×16，96×96 | ARGB4 | ~300 KB |
| 图标 ×3，140×140 | ARGB4 | ~120 KB |
| 二维码缓冲 | L1 260×260 | ~9 KB |
| 合计 | | ~830 KB，RAM_G 1 MB 内 |

BT820 可换 ASTC 6×6 进一步压缩，或字体扩大到 1000 字。

### 9.2 显示列表结构

```
DL_STATIC_TOPBAR   顶栏底、桩号、分隔线        → CMD_APPEND 复用
DL_PAGE_BG[n]      每页静态背景、卡片框、标签    → 页面切换时 CMD_APPEND
DL_DYNAMIC         数字、进度条、图标、按钮态    → 每帧重建，< 40 条指令
```

每帧流程：CMD_DLSTART → APPEND(topbar) → APPEND(page_bg) → 动态部分 → CMD_SWAP。充电中页动态部分约 30 条，30 fps 下 SPI 占用 < 15%。

### 9.3 TAG 映射

| TAG | 控件 |
|---|---|
| 1 | 顶栏桩号（长按进 Settings） |
| 2 | 语言切换 |
| 10 | 取消（授权页） |
| 11 | 停止充电 |
| 12 | 弹窗-取消 |
| 13 | 弹窗-停止 |
| 14 | 完成 |
| 15 | 重试 |
| 20–31 | PIN 键盘 |

TAG 0 保留为无控件。每页只启用本页 TAG，其余触控视为无效。

### 9.4 触控处理（MCU 侧伪代码）

```c
bool contact = rd32(REG_TOUCH_SCREEN_XY) != 0x80008000;
uint8_t tag = contact ? rd8(REG_TOUCH_TAG) : 0;
if (!touch_allowed || touch_area > RAIN_THRESHOLD) {
    cancel_gesture_until_physical_lift();
    return;
}
if (gesture_cancelled) {
    if (!contact) gesture_cancelled = false;
    return;
}
if (contact && pressed_tag && tag != pressed_tag) {
    cancel_gesture_until_physical_lift();  // Dragged away or tag rejected
    return;
}
if (tag && debounce_down_ok(tag)) pressed_tag = tag;
if (tag == TAG_STOP && hold_ms >= 1500) stop_charging_now();
if (!contact && debounce_up_ok()) dispatch_release(page_fsm, pressed_tag);
```

### 9.5 亮度与休眠

- 光敏 ADC → REG_PWM_DUTY 映射：< 50 lux → 30%，> 5000 lux → 100%，中间线性，5 s 滑动平均防闪烁。
- Idle 页 5 min 无插枪 → 亮度降至 15%，检测到插枪或触控立即恢复。
- 故障页强制 100%。

### 9.6 二维码

授权 URL 由后台下发，MCU 用 qrencode 生成 L1 位图（版本 6，41×41 模块，每模块 6 px = 246 px），CMD_LOADIMAGE 或直接写 RAM_G 后 BITMAP 绘制，四周留白靠背景。
